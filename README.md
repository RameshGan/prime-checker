# Prime Wizard

✨ A Python implementation of a prime number calculator. Generates prime numbers, composite numbers up to a specified limit

## 🚀 Features

* Module Provides functions for
  * Calculating and listing prime numbers up to specified limit.
  * Calculating composite numbers, with optional primes provided as input
  * Checking if a given number is a prime number
* The program lists prime numbers and composite numbers up to a limit
* Basic tests for Continuous Integration (CI)

### ⚙️ Technology
