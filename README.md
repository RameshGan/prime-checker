# Prime Wizard

✨ A Python implementation of a Prime Number calculator. Generates prime numbers up to a specified limit

## 🚀 Features

* Module Provides functions for
    * Calculating and listing prime numbers up to specified limit.
    * Checks if a given number is a prime number
* The program lists prime numbers up to 100
* Basic tests for Continuous Integration (CI)
